## Explanation

**Markdown** is a lightweight markup language used to format and structure plain text using simple symbols.

It allows you to create headings, lists, links, images, tables and code blocks without needing a visual editor or complex formatting tools.

Markdown files use the `.md` extension and can be opened and edited with any text editor.

For example, `# Title` creates a heading, `**text**` makes text bold, and `[text](url)` creates a link.

Obsidian uses Markdown to store notes as regular text files, while adding features such as internal links (`[[Note name]]`), backlinks and graph visualization.
