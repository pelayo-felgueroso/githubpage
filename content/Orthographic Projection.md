## Explanation

Orthographic Projection is a way of representing a 3D scene in a 2D image using parallel projection rays. Unlike [[Perspective Projection]], the apparent size of an object does not change with its distance from the camera.

This means that two identical objects will have the same size in the image, even if one is much farther away than the other. Depth does not affect the projected size.

Orthographic projection is commonly used in technical drawings, CAD and engineering applications because it preserves dimensions and makes it easier to compare object sizes.

In Computer Vision, telecentric lenses can approximate orthographic projection. They are particularly useful in industrial inspection and metrology, where measurements should not change significantly with the distance between the object and the camera.
