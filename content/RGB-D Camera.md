## Explanation

An RGB-D camera is a camera system that captures both colour information and depth information.

The RGB image contains the colour of each pixel, while the depth image provides an estimate of the distance between the camera and the corresponding points in the scene.

Depth can be measured using different technologies, such as stereo vision, structured light or time-of-flight sensors. Each approach has different characteristics and limitations. For example, some technologies can be affected by sunlight, reflective surfaces or the distance to the object.

Combining colour and depth information makes it possible to understand not only what an object looks like, but also where it is located in three-dimensional space.

RGB-D cameras are widely used in robotics for object detection, pose estimation, obstacle avoidance and manipulation tasks. The depth information can also be converted into a [[Point Clouds|point cloud]] to represent the environment in 3D.
