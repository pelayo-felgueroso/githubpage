## Explanation

Neural Networks are machine learning models inspired by the way biological neurons are connected. They consist of layers of interconnected units, usually called neurons, that process information.

A basic neural network has an input layer, one or more hidden layers and an output layer. Each connection has a weight that determines how much influence one neuron has on another.

During training, the network adjusts these weights to reduce the difference between its predictions and the expected results. This is usually done through backpropagation, which calculates how the prediction error depends on each weight, and an optimisation algorithm that updates the weights.

Neural networks can learn complex relationships from data. They are used in image classification, object detection, language processing and robotics.

[[Deep Learning]] refers to neural networks with multiple layers that can learn increasingly complex representations. For example, in image processing, early layers may detect simple patterns such as edges, while deeper layers can recognise more complex shapes and objects.
