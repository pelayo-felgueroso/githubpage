## Explanation

Object Tracking is the process of following an object across a sequence of images or video frames.

The goal is to identify the same object over time and estimate its position as it moves through the scene. A tracking system usually starts by detecting or selecting an object and then updates its location in subsequent frames.

Tracking methods can use visual features, object appearance, motion information or deep learning models. Some approaches track a single object, while others can track several objects at the same time.

Object tracking is closely related to [[Object Detection]], but they solve different problems. Object detection identifies objects in individual images, while tracking connects detections across multiple frames to understand how objects move over time.

Tracking is used in applications such as surveillance, autonomous driving, sports analysis and robotics. In robotics, it can help a system follow a moving object or maintain an estimate of an object's position while the robot interacts with it.
