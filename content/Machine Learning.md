## Explanation

Machine Learning is a branch of [[Artificial Intelligence]] where computer systems learn patterns from data instead of relying only on explicitly programmed rules.

A machine learning model is trained using examples and tries to identify relationships that can be used to make predictions or decisions on new data.

There are three common learning approaches:

- Supervised learning uses labelled examples. For example, a model can learn to distinguish between different types of objects using images with known labels.
    
- Unsupervised learning finds patterns or structures in data without predefined labels. It can be used to group similar samples or reduce the number of dimensions in a dataset.
    
- Reinforcement learning learns through interaction with an environment. The model receives rewards or penalties and tries to improve its behaviour over time.
    

Machine learning is used in many areas, including computer vision, robotics, medical imaging and natural language processing.

[[Deep Learning]] is a subfield of machine learning based on neural networks with multiple layers. It is particularly useful when working with complex data such as images, audio and text.
