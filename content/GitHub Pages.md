## Explanation

[GitHub Pages](https://pages.github.com/) is a service from GitHub that allows you to publish websites directly from a GitHub repository. It is mainly used for static websites, meaning pages built with HTML, CSS and JavaScript that don't need a server to generate content every time someone visits.

The basic idea is to store your website files in a [[GitHub]] repository and let GitHub Pages host them online. Whenever you push changes to the repository, the website can be updated automatically.

You can also use a Static Site Generator to turn content written in [[Markdown]] into a complete website. For example, [[Quartz]] can take notes from an [[Obsidian]] vault and generate a website that can then be published through GitHub Pages.
