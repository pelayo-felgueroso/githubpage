## Explanation

Quartz is a static site generator designed to publish personal knowledge bases, digital gardens and collections of Markdown notes as websites.

It takes Markdown files, processes their content and converts them into a website that can be hosted online.

Quartz supports features such as internal links, backlinks, search, graph visualization, tags and navigation between notes.

It is particularly useful for publishing an [[Obsidian]] vault while preserving the connections between notes.
