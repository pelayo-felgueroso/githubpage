## Explanation

A pixel is the smallest addressable element of a digital image. Each pixel stores information about the image at a specific position.

In a grayscale image, a pixel usually contains a single intensity value. In a colour image, it can contain several values representing different colour channels, such as Red, Green and Blue.

For an 8-bit grayscale image, pixel values typically range from 0 to 255, where 0 represents black and 255 represents white. In an RGB image, each channel usually has its own intensity value.

The number of pixels determines the image dimensions and contributes to its resolution. However, the physical size represented by each pixel also depends on factors such as camera calibration, lens properties and the distance to the object.

Pixels are the basic units used by image processing and computer vision algorithms. Operations such as filtering, thresholding and edge detection work by analysing or modifying pixel values.
